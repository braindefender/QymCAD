# FreeCAD Classic Icon Theme

Classic colored tool icons ported from the FreeCAD project for **QymCAD**.

## Overview
- **ID**: `freecad-classic`
- **Name**: FreeCAD Classic
- **Color Mode**: `Universal` (multi-color icons rendered in their native colors across all UI schemes)
- **Author**: FreeCAD Contributors
- **License**: LGPL-2.1-or-later
- **Coverage**: 100% (107/107 CAD icons)

## Icon Categories
- **Sketcher**: Lines, arcs, circles, rectangles, polygons, splines, fillets, trims, and offsets.
- **Constraints**: Coincident, point on object, horizontal, vertical, parallel, perpendicular, tangent, equality, and dimensions.
- **Part Design**: Extrude, revolve, loft, sweep, fillet, chamfer, draft, hole, boolean operations, and patterns.
- **Assembly**: Ground, relations, joints, insert components, subassemblies, and arrays.
- **Datum & View**: Coordinate systems, planes, axes, points, view cube, and measure tools.
