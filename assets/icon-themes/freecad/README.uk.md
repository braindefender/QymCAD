# Класична тема іконок FreeCAD

Класичні кольорові іконки інструментів проєкту FreeCAD, адаптовані для **QymCAD**.

## Огляд

- **ID:** `freecad-classic`
- **Назва:** FreeCAD: класичні іконки.
- **Колірний режим:** `Universal` — вихідні кольори іконок зберігаються за будь-якої колірної теми інтерфейсу.
- **Автор:** учасники проєкту FreeCAD.
- **Ліцензія:** LGPL-2.1-or-later.
- **Покриття:** 100% (107 зі 107 іконок CAD).

## Категорії іконок

- **Ескіз:** лінії, дуги, кола, прямокутники, багатокутники, сплайни, скруглення, обрізка та зміщення.
- **Обмеження:** збіг, точка на об'єкті, горизонтальність, вертикальність, паралельність, перпендикулярність, дотичність, рівність і розміри.
- **Проєктування деталей:** видавлювання, обертання, лофт, протяжка, скруглення, фаска, отвір, булеві операції та масиви.
- **Збірка:** фіксація, зв'язки, з'єднання, вставка компонентів, підзбірки та масиви.
- **Базова геометрія та вигляд:** системи координат, площини, осі, точки, куб вигляду та інструменти вимірювання.
