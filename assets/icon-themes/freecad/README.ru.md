# Классическая тема иконок FreeCAD

Классические цветные иконки инструментов проекта FreeCAD, адаптированные для **QymCAD**.

## Обзор

- **ID:** `freecad-classic`
- **Название:** FreeCAD: классические иконки.
- **Цветовой режим:** `Universal` — исходные цвета иконок сохраняются при любой цветовой теме интерфейса.
- **Автор:** участники проекта FreeCAD.
- **Лицензия:** LGPL-2.1-or-later.
- **Покрытие:** 100% (107 из 107 иконок CAD).

## Категории иконок

- **Эскиз:** линии, дуги, окружности, прямоугольники, многоугольники, сплайны, скругления, обрезка и смещение.
- **Ограничения:** совпадение, точка на объекте, горизонтальность, вертикальность, параллельность, перпендикулярность, касание, равенство и размеры.
- **Проектирование деталей:** выдавливание, вращение, лофт, протяжка, скругление, фаска, отверстие, булевы операции и массивы.
- **Сборка:** фиксация, связи, соединения, вставка компонентов, подсборки и массивы.
- **Базовая геометрия и вид:** системы координат, плоскости, оси, точки, куб вида и инструменты измерения.

## Источник и авторство

Иконки адаптированы из наборов инструментов FreeCAD и распространяются по условиям GNU Lesser General Public License версии 2.1 или более поздней.
