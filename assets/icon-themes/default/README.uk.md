# Стандартна тема векторних іконок

Вбудований монохромний набір векторних іконок для **QymCAD**.

## Огляд

- **ID:** `default`
- **Колірний режим:** `Monochrome` — колір іконок підлаштовується під колір тексту у світлій та темній темах інтерфейсу.
- **Покриття:** 100% (107 зі 107 іконок CAD).
- **Ліцензія:** MIT / Apache-2.0.
- **Базовий шар:** так; використовується, коли потрібної іконки немає в наборах з вищим пріоритетом.

## Особливості

- **Область перегляду SVG:** квадрат 64 × 64.
- **Стиль:** прості геометричні контури та лінії на основі рекомендацій Phosphor.
- **Контрастність:** SVG використовують `currentColor` або не задають колір заливки жорстко, тому іконки залишаються чіткими в різних колірних темах.
- **Резервні іконки:** якщо вибраний набір не містить іконку інструмента, QymCAD показує відповідну іконку з цього набору.
