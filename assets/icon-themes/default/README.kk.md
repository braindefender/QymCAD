# Векторлық таңбашалардың стандартты тақырыбы

**QymCAD** үшін кірістірілген монохромды векторлық таңбашалар жиынтығы.

## Шолу

- **ID:** `default`
- **Түс режимі:** `Monochrome` — интерфейстің ашық және күңгірт тақырыптарында таңбашалар түсі мәтін түсіне бейімделеді.
- **Қамту:** 100% (107/107 CAD таңбашасы).
- **Лицензия:** MIT / Apache-2.0.
- **Негізгі қабат:** иә; басымдығы жоғары жиынтықтарда қажетті таңбаша болмаған кезде қолданылады.

## Ерекшеліктері

- **SVG қарау аймағы:** 64 × 64 шаршы.
- **Стилі:** Phosphor ұсыныстарына негізделген қарапайым геометриялық контурлар мен сызықтар.
- **Контраст:** SVG файлдары `currentColor` қолданады немесе бояу түсін қатаң белгілемейді, сондықтан таңбашалар әртүрлі түс тақырыптарында айқын көрінеді.
- **Резервтік таңбашалар:** егер таңдалған жиынтықта құрал таңбашасы жоқ болса, QymCAD осы жиынтықтағы сәйкес таңбашаны көрсетеді.
