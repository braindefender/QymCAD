# Стандартная тема векторных иконок

Встроенный монохромный набор векторных иконок для **QymCAD**.

## Обзор

- **ID:** `default`
- **Цветовой режим:** `Monochrome` — цвет иконок подстраивается под цвет текста в светлой и тёмной темах интерфейса.
- **Покрытие:** 100% (107 из 107 иконок CAD).
- **Лицензия:** MIT / Apache-2.0.
- **Базовый слой:** да; используется, когда нужной иконки нет в наборах с более высоким приоритетом.

## Особенности

- **Область просмотра SVG:** квадрат 64 × 64.
- **Стиль:** простые геометрические контуры и линии на основе рекомендаций Phosphor.
- **Контрастность:** SVG используют `currentColor` либо не задают цвет заливки жёстко, поэтому иконки остаются различимыми в разных цветовых темах.
- **Запасные иконки:** если выбранный набор не содержит иконку инструмента, QymCAD показывает соответствующую иконку из этого набора.
