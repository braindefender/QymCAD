# Shapr-Alike

Shapr3D үлгісінде жасалған QymCAD таңбашалары.

## Шолу

- **ID:** `shapr-alike`
- **Атауы:** Shapr-Alike
- **Нұсқасы:** `1.0.0`
- **Пакет түрі:** `IconTheme`
- **Түс режимі:** `Universal` — интерфейстің кез келген түс тақырыбында таңбашалардың төл түстері сақталады.
- **Авторы:** braindefender
- **Лицензиясы:** AGPL-3.0-or-later.
- **Қамту:** 100% (95/95 CAD таңбашасы).

- **Эскіз** (32): сызықтар, доғалар, шеңберлер, тіктөртбұрыштар, көпбұрыштар, ойықтар, эллипстер, сплайндар, дөңгелектеулер, фаскалар, кесу, созу, ығыстыру, өлшемдер және түрлендіру құралдары.
- **Байланыстар** (12): сәйкестік, коллинеарлық, концентрлілік, теңдік, көлденеңдік, тіктік, параллельдік, перпендикулярлық, жанасу, симметрия, ортаңғы нүкте және бекіту.
- **Бөлшек** (34): сығу, айналдыру, лофт, сырғыту, дөңгелектеу, фаска, еңістік, қабықша, саңылау, бұранда, логикалық амалдар, бөлу, массивтер, айна, өлшеу және қарапайым денелер.
- **Жинақ** (10): бекіту, байланыстар, қосылыстар, компоненттерді кірістіру, жаңа бөлшек, ішкі жинақтар, топтар, массивтер және ені/жанасу құралдары.
- **Негізгі геометрія** (4): жазықтықтар, осьтер, нүктелер және эскиз жазықтығын таңдау.
