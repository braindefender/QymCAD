* **Статус:** Схвалено до реалізації (Approved)
* **Дата оновлення:** 2026-10-03
* **Область:** `qymcad-ui-state`, `qymcad-render`, `qymcad-shell`, `qymcad`
* **Відповідність правилам репозиторію:** Повністю відповідає `CLAUDE.md` (розділи Resources, Tests, God Object Ratchet, Dependency Ratchet).

## 1. Контекст та мотивація

### 1.1. Поточний стан
У QymCAD інтерфейсні іконки реалізовані через іконковий шрифт **Phosphor Icons** (`egui-phosphor`, версія Regular). 

Незважаючи на легкість масштабування шрифту, поточне рішення має принципові обмеження:
1. **Брак CAD-символіки:** У шрифті Phosphor відсутні специфічні позначення САПР (коло по 3 точках, еліпс за центром і радіусами, типи інженерних з'єднань, обмеження ескізу). Через це розробникам довелося вручну розраховувати координати ліній та дуг у функціях `paint_gly` та `sym_button` через `egui::Painter`.
2. **Монохромність:** Шрифт не дозволяє використовувати наочні кольорові іконки операцій (наприклад, звичне для інженерів кольорове кодування операцій у стилі SolidWorks, Inventor або FreeCAD).
3. **Неможливість розширення без перекомпіляції:** Користувачі та майбутні плагіни не можуть додати новий гліф у запечений TrueType-шрифт програми.

### 1.2. Мета
Створити модульну, відкриту та гнучку систему динамічних векторних тем іконок (SVG), яка:
* Підтримує як повноколірні, так і монохромні векторні іконки.
* Дозволяє користувачам легко завантажувати, вмикати, вимикати та комбінувати бандли іконок.
* Реалізує каскадний багаторівневий пошук (fallback) із гарантованим вбудованим базовим рівнем.
* Інтегрується з майбутньою системою плагінів як декларативний плагін-ресурс (`package_type: IconTheme`).
* Надає розробникам тем зручний режим розробки з гарячим перезавантаженням та генератором пакетів в один клік.

## 2. Відповідність архітектурним правилам репозиторію (`CLAUDE.md`)

У зв'язку з появою офіційного склепіння правил `CLAUDE.md` та автоматичних сторожів (guards), архітектура іконкової системи проєктується строго з урахуванням таких вимог:

1. **Класифікація як Resource:** Згідно з `CLAUDE.md`, набори іконок класифікуються саме як **ресурс** (*«A resource — a file a person brings and chooses without rebuilding the program ... Built-in ones through include_dir, the user's in ProjectDirs»*). Вбудовані теми вшиваються в бінарник, користувацькі шукаються в `ProjectDirs`.
2. **Сторож `god_object_ratchet`:** **Жоден рядок не додається в `impl App`**. Структура `IconManager` живе у `qymcad-ui-state` і передається у функції відмальовування через контекстні структури (`BarCtx`, `WinCtx`), або резолвиться як статичний ресурс.
3. **Сторож `dependency_ratchet`:** Нова залежність `egui_extras` (з фічею `svg`) обов'язково реєструється у файлі `tools/deps.toml`.
4. **Сторож `gui/font_coverage.rs`:** Зберігається непорушність правила `ph::*` для текстових рядків та i18n-каталогів. Вбудований fallback на `ph::*` гарантує, що старі перевірки не зламаються.
5. **Вимоги до тестів (`tools/pr_tests.py`):** Будь-який функціонал покривається тестами (парсинг маніфестів, fallback-ланцюжок, валідація SVG, acceptance тести вибору теми).

## 3. Ключові принципи архітектури

1. **Векторний формат (SVG 1:1):** Усі іконки створюються у векторному форматі SVG із фіксованим `viewBox="0 0 64 64"`. Забороняється вбудовування растрових даних (`base64`).
2. **Жорстка конвенція шляхів та імен:** Відмова від складних конфігурацій мапінгу. Шлях до файлу в теці однозначно визначає його системний ідентифікатор: `icons/sketch/line.svg` $\rightarrow$ `sketch.line`.
3. **Каскадний стек пріоритетів (Fallback Cascade):** Інтерфейс підтримує список активних наборів з регулюванням пріоритету (зверху вниз). Запитувана іконка шукається послідовно:
   $$\text{Pack}_1 \longrightarrow \text{Pack}_2 \longrightarrow \dots \longrightarrow \text{Base Built-in (Phosphor / Default SVG)}$$
   Вбудований базовий набір завжди присутній у самому низу стека і гарантує, що жоден інструмент не залишиться без кнопки.
4. **Підтримка двох форматів бандлів:**
   * **Тека на диску:** Для розробки та легкого редагування файлів у режимі реального часу.
   * **Архів `.qicons` (zip):** Робочий формат для розповсюдження кінцевим користувачам. Використовує швидке стиснення (`Deflate`/`Store`) для мінімізації навантаження на I/O.
5. **Інтеграція в плагінну систему:** Маніфест містить дескриптор типу пакета, що робить його повноцінним плагіном у майбутньому реєстрі розширень.

### 4.2. Маніфест пакета (`manifest.ron`)
Маніфест описується мовою RON (Rusty Object Notation) і відповідає стандарту проекту:

```ron
(
    // Тип пакета для сумісності з плагінною системою
    package_type: IconTheme,

    // Унікальний строковий ідентифікатор
    id: "freecad-classic",

    // Людиночитабельна назва та версія
    name: "FreeCAD Classic",
    version: "1.0.0",
    author: "FreeCAD Contributors",
    license: "LGPL-2.1-or-later",
    description: "Classic multi-color CAD tool icons from FreeCAD project",

    // Режим роботи з кольором:
    // - Universal: повноколірні іконки, відображаються як є на будь-якій темі
    // - Monochrome: одноколірні іконки, динамічно тонуються кольором тексту поточної теми UI
    color_mode: Universal,
)
```

### 4.3. Вимоги до SVG-файлів
1. **ViewBox:** Обов'язково `viewBox="0 0 64 64"`.
2. **Векторна чистота:** Тільки векторні теги (`<path>`, `<circle>`, `<rect>`, `<polygon>`, `<g>` тощо). Заборонено використання растрових вставок (`<image>`).
3. **Кольори у режимі Monochrome:** Для монохромних наборів рекомендується використовувати `fill="currentColor"` або чистий білий `#FFFFFF` колір для коректного динамічного тонування через шейдер/маску `egui`.

## 5. Архітектура підсистеми в коді

### 5.1. Стек залежностей
* `egui_extras = { version = "0.35", features = ["svg"] }` — офіційний засіб растеризації SVG у текстури під поточний масштаб екрану (`pixels_per_point`).
* `zip` — уже підключено в проекті, використовується для читання `.qicons`.
* `ron` — уже підключено в проекті, використовується для десеріалізації маніфестів.

### 5.2. Ключові структури даних

```rust
/// Унікальний логічний ідентифікатор інструмента/дії
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum IconId {
    SketchLine,
    SketchCircle,
    SketchCircle3Pt,
    SketchRect,
    PartExtrude,
    PartRevolve,
    PartFillet,
    // ...
}

impl IconId {
    /// Шлях усередині папки icons/ без розширення .svg
    pub fn relative_path(&self) -> &'static str {
        match self {
            Self::SketchLine => "sketch/line",
            Self::SketchCircle3Pt => "sketch/circle_3pt",
            Self::PartExtrude => "part/extrude",
            // ...
        }
    }
}

/// Режим кольору бандлу
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
pub enum ColorMode {
    Universal,
    Monochrome,
}

/// Пакет іконок (завантажений з папки або .qicons)
pub struct IconPack {
    pub manifest: IconManifest,
    pub source: PackSource, // Directory(PathBuf) або Archive(PathBuf)
}

/// Центральний менеджер іконок (живе у qymcad-ui-state, не в App)
pub struct IconManager {
    /// Активний стек бандлів (від найвищого пріоритету до найнижчого)
    pub active_stack: Vec<IconPack>,
    /// Кеш завантажених SVG-зображень (текстур egui)
    cache: HashMap<(IconId, u64), egui::Image<'static>>,
    /// Прапорець фонового відстеження змін файлів (для Dev Mode)
    pub dev_watch_enabled: bool,
}
```

### 5.3. Каскадний резолвер (Fallback Logic)
```rust
impl IconManager {
    pub fn resolve(&self, id: IconId, ui: &egui::Ui) -> ResolvedIcon {
        let rel_path = format!("{}.svg", id.relative_path());

        // 1. Пошук по стеку активних паків зверху вниз
        for pack in &self.active_stack {
            if let Some(svg_data) = pack.load_svg(&rel_path) {
                let img = self.create_image(id, svg_data, &pack.manifest.color_mode, ui);
                return ResolvedIcon::Svg(img);
            }
        }

        // 2. Вбудований fallback (Phosphor Glyph або базовий процедурний символ)
        ResolvedIcon::FallbackGlyph(id.fallback_glyph())
    }
}
```

### 5.4. Збереження конфігурації
У структуру `qymcad_ui_state::Settings` додаються поля:
```rust
#[derive(Clone, serde::Serialize, serde::Deserialize)]

    /// Ідентифікатори вимкнених користувацьких бандлів

```

## 6. Інтерфейс користувача та режим розробника

### 6.1. Вікно налаштувань (Settings $\rightarrow$ Icons)
Інтерфейс містить два списки з кнопками перенесення та зміни пріоритету:
```text
┌─ Доступні набори ──────────────┐     ┌─ Активні набори (Пріоритет) ───┐
│ [FreeCAD Classic (SVG)]        │ ──> │ 1. [My Custom Sketch Icons]  ▲ │
│ [Flat Dark Minimal]            │ <── │ 2. [FreeCAD Classic (SVG)]   ▼ │
│                                │     │ 3. [Вбудований (Phosphor)]  🔒 │
└────────────────────────────────┘     └────────────────────────────────┘
[ 📂 Встановити .qicons... ]            [ 📁 Відкрити папку наборів ]
```
* Перемикання тем працює на льоту без перезапуску застосунку (кеш інвалідується через `ctx.forget_image`).
* Вбудований базовий набір зафіксований на позиції найнижчого пріоритету.

### 6.2. Режим розробника (Developer Tools)
Для авторів тем передбачено два інструменти прямо в інтерфейсі QymCAD:

1. **Гаряче перезавантаження (Live Watch Mode):**
   * Кнопка-тумблер: `[x] Автоматично відстежувати зміни файлів у папці теми`.
   * При збереженні будь-якого SVG у редакторі (наприклад, Inkscape) іконка в тулбарі QymCAD оновлюється миттєво.
   * Окрема кнопка ручного оновлення: `[🔄 Скинути кеш іконок]`.

2. **Майстер складання бандлу (Bundle Packager):**
   * Кнопка: `[ 📦 Запакувати тему в .qicons ]`.
   * Відкриває діалогове вікно з формою:
     * Назва теми, Автор, Ліцензія, Опис.
     * Вибір режиму (`Universal` / `Monochrome`).
     * Вибір робочої папки з іконками.
   * Дія:
     * Валідує структуру папок та перевіряє SVG на `viewBox="0 0 64 64"`.
     * Попереджає про відсутні іконки (наприклад: *«Покрито 48 із 60 іконок»*).
     * Автоматично генерує валідний `manifest.ron`.
     * Пакує вміст у готовий файл `назва-теми.qicons` без зайвих ручних дій.

## 7. Еталонний бандл: «FreeCAD Classic»

* **Джерело:** Офіційний репозиторій FreeCAD (`src/Mod/PartDesign/Gui/Resources/icons/`, `src/Mod/Sketcher/...`).
* **Ліцензія:** GNU LGPL-2.1-or-later (повністю сумісна з AGPLv3 ліцензією QymCAD).
* **Склад:**
  * Повний набір інструментів ескізника (відрізок, коло, прямокутник, дуга, фаска, скруглення, розміри).
  * Повний набір твердотільного моделювання (витягування, обертання, скруглення тіла, фаска, тонкостінна оболонка, булеві операції).
* **Постачання:** Бандл поставляється або вбудованим поруч із виконуваним файлом, або доступним для завантаження в один клік.
